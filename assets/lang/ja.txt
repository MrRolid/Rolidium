# ---- hints ----
Click to finish, or type a size (Tab: next field, Enter: confirm, Esc: cancel shape). => クリックで確定、またはサイズを入力します (Tab: 次の欄、Enter: 確定、Esc: 図形を取消)。
Sketch: L line, R rectangle, C circle. V faces the sketch, D or P leaves. => スケッチ: L 直線、R 長方形、C 円。V でスケッチに正対、D または P で終了します。
Click to place the first point. Esc/right click cancels, D or P leaves the sketch. => クリックして最初の点を置きます。Esc/右クリックで取消、D または P でスケッチを終了します。
Up to: click a face, an edge, a vertex or a point on a face. Esc cancels. => ここまで: 面、エッジ、頂点、または面上の点をクリックします。Esc で取消します。
Pull: type the distance (negative removes material). Enter applies, Esc cancels. => プル: 距離を入力します (負の値で材料を除去)。Enter で適用、Esc で取消します。
Pull: drag along the normal (snaps to faces, vertices and the grid; hold Shift for free movement), or type a number. => プル: 法線方向にドラッグします (面や頂点、グリッドにスナップ。Shift を押すと自由に移動)。または数値を入力します。
Select: click a face or a sketch region. K sketches on the selected flat face (or the base plane). => 選択: 面またはスケッチ領域をクリックします。K で選択した平面(またはベース平面)にスケッチします。
Pull: drag a flat face or a sketch region (out adds, in removes). Or select one and type a distance. U pulls up to a target. => プル: 平らな面またはスケッチ領域をドラッグします (外側は追加、内側は除去)。または選択して距離を入力します。U で対象までプルします。

Click a face, an edge, a sketch shape or a sketch region to select it. Ctrl+click adds to the selection. The object under the cursor is highlighted. => 面、エッジ、スケッチ図形、スケッチ領域をクリックして選択します。Ctrl+クリックで選択に追加します。カーソル下のオブジェクトはハイライト表示されます。
Click empty space to clear the selection. => 何もない場所をクリックすると選択が解除されます。
A small panel appears next to the selection: sizes of holes, pins, rounds and sketch shapes, and Move by for flat faces. => 選択の横に小さなパネルが表示されます: 穴、ピン、フィレット、スケッチ図形のサイズと、平らな面の移動量を設定できます。
Drag a flat face or a sketch region along its normal: out adds material, in removes it. Drag a selected edge to round it. Type a number to enter an exact value, Enter applies, Esc cancels. => 平らな面またはスケッチ領域を法線方向にドラッグします: 外側は材料を追加、内側は除去します。選択したエッジをドラッグするとフィレットになります。数値を入力すると正確な値を指定でき、Enter で適用、Esc で取消します。
The distance snaps to other faces and vertices (also of other bodies) and otherwise to the grid. Hold Shift while dragging to turn snapping off. => 距離は他の面や頂点 (他のボディも含む) にスナップし、それ以外はグリッドにスナップします。ドラッグ中に Shift を押すとスナップが無効になります。
U (Up to) pulls the selected face to a face, edge, vertex or point you click. => U (ここまで) は、選択した面をクリックした面、エッジ、頂点、点までプルします。
The panel's Mode forces Add or Cut whichever way you pull. => パネルのモードで、プルする向きに関係なく追加またはカットに固定できます。
Starts a sketch on the selected flat face, or on the base plane (XY) if no flat face is selected. Draw with Line, Rectangle and Circle, then leave with D or P. => 選択した平らな面、または平らな面がなければベース平面 (XY) にスケッチを開始します。直線、長方形、円で描き、D または P で終了します。
Closed shapes get a light fill: that is what Pull can extrude. => 閉じた図形は淡く塗りつぶされます: プルで押し出せるのはこの図形です。
Click the start point, then the end point. The next line starts where the last one ended. Type a length and an angle if you want exact values. => 始点をクリックし、次に終点をクリックします。次の直線は前の終点から始まります。正確な値にしたい場合は長さと角度を入力します。
Tab switches between the length and angle fields. => Tab で長さと角度の欄を切り替えます。
Esc or a right click stops drawing. => Esc または右クリックで描画を中止します。
Click one corner, then the opposite corner. Type width and height for exact sizes, Tab switches the field, Enter confirms. => 一方の角をクリックし、次に対角をクリックします。正確なサイズは幅と高さを入力し、Tab で欄を切り替え、Enter で確定します。
Rectangles are always parallel to the sketch axes. => 長方形は常にスケッチの軸に平行です。
Click the centre, then a point on the circle. Or type the diameter and press Enter. => 中心をクリックし、次に円周上の点をクリックします。または直径を入力して Enter を押します。
Snap to a circle's centre to draw concentric circles. => 円の中心にスナップすると同心円を描けます。
Turns the view straight onto the sketch plane so you can draw without perspective distortion. => 遠近感の歪みなく描けるよう、ビューをスケッチ平面に正対させます。
Mouse wheel zooms towards the cursor. => マウスホイールでカーソル位置に向かってズームします。
Leaves the sketch and returns to normal 3D work. P does the same and switches to Pull. => スケッチを終了して通常の3D作業に戻ります。P も同じで、プルに切り替わります。
Takes back the last change: a drawn shape, a pull, a rounding. There is no limit on the number of steps. => 直前の変更を取り消します: 描いた図形、プル、フィレットなど。ステップ数に制限はありません。
Re-applies a change that was undone. Making a new change clears the redo steps. => 取り消した変更をもう一度適用します。新しい変更を行うと、やり直しの履歴は消去されます。
Looks at the model from above. => モデルを上から見ます。
Looks at the model from the front. => モデルを正面から見ます。
Looks at the model from the right side. => モデルを右側から見ます。

Zooms so that everything in the scene is visible. => シーン全体が見えるようにズームします。
Opens the export dialog: choose where to save and how fine the triangles should be. The dialog shows the resulting number of triangles and file size. => 書き出しダイアログを開きます: 保存先と三角形の細かさを選びます。ダイアログには三角形の数とファイルサイズが表示されます。
Binary STL is much smaller than ASCII. => バイナリSTLはASCIIよりずっと小さくなります。
Finer settings give smoother circles and larger files. => 細かい設定ほど円が滑らかになり、ファイルは大きくなります。

The folded row at the bottom of the right column opens a panel. Choose Bug or Idea, write what happened or what you would like (up to 1000 characters) and, if you wish, leave an e-mail for a reply. When you click the row, the program takes a picture of its own window (what you were looking at, before the panel opens); it stays in memory until you send. The diagnostics and the window picture are attached by default to a bug and not to an idea (you can change it); Take again takes the picture again with the panel hidden; Show what is sent lists every file with a check box (window.png first): a file you switch off is not sent. The diagnostics are made in the background from what the program already has in memory (about 2 seconds at most, never more than 5). The test scene of the other graphics interfaces is only in About > Save diagnostics. Nothing is sent before you press Send. If the server does not answer, your text stays and you can save the report to a file. => 右側の列の下にある折りたたまれた行をクリックするとパネルが開きます。「不具合」または「アイデア」を選び、起きたことや希望を書いてください（1000文字まで）。返信用のメールアドレスは任意です。行をクリックすると、プログラムは自分のウィンドウの画像（パネルが開く前に見ていたもの）を撮影します。送信するまではメモリ内にのみ保持されます。診断とウィンドウ画像は、バグには初期設定で添付され、アイデアには添付されません（変更できます）。「撮り直す」はパネルを隠して撮り直します。「送信内容を表示」は各ファイルをチェックボックス付きで一覧します（window.png が先頭）。外したファイルは送信されません。診断情報は、プログラムがすでにメモリに持っている情報からバックグラウンドで準備されます（長くても約2秒、5秒を超えることはありません）。他のグラフィックスインターフェースのテストシーンは、バージョン情報 > 診断を保存 にのみあります。「送信」を押すまで何も送信されません。サーバーが応答しない場合でも、入力したテキストは残り、報告をファイルに保存できます。
An idea needs some text; a bug can be sent without text only with the diagnostics. => アイデアにはテキストが必要です。テキストなしのバグは診断を添付した場合のみ送信できます。
The diagnostics hold no models, no names of models, no name of the computer and no user name. => 診断情報には、モデル、モデル名、コンピューター名、ユーザー名は含まれません。
