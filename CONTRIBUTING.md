# Contributing to Rolidium

Thank you for your interest in Rolidium.

## Ideas and bug reports: welcome

Please use [GitHub Issues](https://github.com/MrRolid/Rolidium/issues):

* **Bug report**: what you did, what you expected and what happened. Add the Rolidium version (status bar or `rolidium --version`) and,
  for graphics problems, the diagnostics zip from *About > Save diagnostics*. The issue form asks for everything that is needed.
* **Idea or feature request**: describe the task you want to do and how you would expect the program to help. A sketch or a picture of
  the part is often more useful than a long text.
* **Translations and text fixes**: wrong or clumsy wording in the interface, in a translation or in the documentation. The German,
  Spanish, French and Japanese translations are machine translations, so corrections from native speakers are especially welcome.

Security problems do not belong in public issues; see [SECURITY.md](SECURITY.md).

By sending ideas, descriptions, suggested wording, translations or text fixes through Issues (or by any other channel), you agree that
Rolid spol. s r.o. may use them without restriction and without payment, in the public version and in commercial versions of Rolidium.

## Code contributions: not accepted for now

Pull requests with code from outside the project are **not accepted at the moment**, and will be closed without review.

The reason, openly: Rolidium keeps a **single copyright holder**, Rolid spol. s r.o. That is what allows the publisher to offer commercial
licences and additional modules alongside the public core under the AGPL (see "The project model" in the [README](README.md)). Code written by others would have its own copyright holders,
and the AGPL part could then no longer be offered under other terms.

This may change later. Code contributions would then be possible with a written agreement that gives the publisher full rights to the
contribution (a contributor licence agreement). If you would like to contribute code under such terms, write to connect@rolid.com.

You are of course free to fork Rolidium under the terms of the AGPL; please read [TRADEMARKS.md](TRADEMARKS.md) about the name and the logo.
