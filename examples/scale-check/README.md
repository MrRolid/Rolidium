# STL scale check

`cube-20.txt` makes a cube of 20 mm and exports it to STL, binary and ASCII. The files must measure 20.000 x 20.000 x 20.000 mm.

Run the check: `scripts/stl-scale-check.sh` (it prints the expected and the measured bounding box of both files).
